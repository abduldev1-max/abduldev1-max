## 🚀 Featured Project

### AI Resume Builder

A full-stack AI-powered web application that helps users create, improve, and optimize professional resumes.

### Features

- 🤖 AI-generated resume content
- 📝 Professional summary generation
- 💼 AI-improved work experience bullet points
- 🎯 ATS resume and job description matching
- 💾 Resume history and version management
- 📄 PDF resume export
- 🔐 Google OAuth 2.0 authentication
- 🔑 Email and password authentication
- 🧠 Multi-model AI integration with Groq/Grok and Google Gemini
- ☁️ Deployed on Render with PostgreSQL
